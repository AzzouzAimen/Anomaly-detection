**Status**: Templates needed ✅

Two identical scripts:

- `scripts/ingest_timescaledb.py` (bulk insert + compression)


**Output**:

- TimescaleDB: apnea_ts_db with same rows (compressed)
- Ingestion logs: `database/{postgresql,timeseries}/ingestion_log.json`

**Key Constraints** (per SG05):

- FK order: subjects → recordings → signals → annotations
- Batch size: fixed 100K rows (not variable)
- TimescaleDB: 1-hour chunks for signals, 1-day chunks for annotations
- Compression: compress_segmentby='recording_id', compress_orderby='recorded_at DESC'

| ----- | --------------------- | ----------------------------------- | ------------------------- |

| **4** | Heart Rate (QRS)      | Count beats per minute              | 10 runs per DB            |
| **5** | Signal-Label Join     | Link signals to apnea labels        | 5 runs (expensive)        |
| **6** | Storage & Compression | Measure disk footprint + ratio      | Pre/post compression      |

## Architecture Decisions Reference

| Decision                 | Spec Reference             | Implementation                                                           |
| ------------------------ | -------------------------- | ------------------------------------------------------------------------ |
| **Synthetic Timestamps** | SG05 Architecture 3.1      | BASELINE_TIMESTAMP = 2000-01-01; timestamp = baseline + sample_index/100 |
| **Frequency Mismatch**   | SG05 Architecture 3.2      | Separate signals & annotations tables, joined via time-range intervals   |
| **Wide Table**           | SG05 Architecture 3.3      | Single signals table with nullable resp/spo2 columns (not EAV)           |
| **Hypertable Chunks**    | SG05 Architecture 3.4      | Signals: 1-hour chunks; Annotations: 1-day chunks                        |
| **Compression**          | SG05 Architecture 3.5      | compress_segmentby='recording_id', compress_orderby='recorded_at DESC'   |
| **ETL Extract**          | SG05 Ingestion, Section A  | Use wfdb library; detect combined headers                                |
| **ETL Transform**        | SG05 Ingestion, Section B  | Flatten to rows; map 'A'/'N' → TRUE/FALSE; generate timestamps           |
| **ETL Load**             | SG05 Ingestion, Section C  | FK order: subjects→recordings→signals→annotations; 100K batches          |
| **Benchmarks**           | SG05 Benchmarking Protocol | 6 tests with specific SQL queries                                        |
